# Shell icon font

`Phosphor-Bold.ttf` is bundled from [Phosphor Web v2.1.2](https://github.com/phosphor-icons/web/tree/v2.1.2/src/bold), matching the existing installer and Nix package. Quickshell loads it directly so user font substitutions cannot change icon meanings.
