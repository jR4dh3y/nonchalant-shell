# Nonchalant Purple

Dark mode follows the existing Waybar Nonchalant-Purple palette in
`.config/themes/global-colors.css` in the parent repository. Waybar imports
that file from `.config/waybar/style.css`.

Normal foreground is purple `#c59edc`, selected/focused controls use lime
`#c3fb5b`, backgrounds are `#1e1e20`, and panels are `#2a2a2c`. The neutral
accent is `#dcd9e7`. Terminal slots retain the existing Kitty palette.
Additional shell container levels and paired foregrounds fill the shell's
color contract. Light mode is derived from these hues; the original desktop
scheme defines dark mode only.
